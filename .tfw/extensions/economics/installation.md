# Economics compatibility installation guidance

Economics is standard, installed and updated by the pinned adapter manifest through
`.tfw/workflows/init.md`, `update.md` and `config.md`. The sole canonical behavior is
`.tfw/workflows/economics.md`; Codex/Antigravity use its standard thin entry and Claude/Cursor
its full canonical command copy. Standalone Coordinator scope preserves the four formal roles;
active task analysis retains its current Role Lock. Daily remains a separate optional package.

Existing optional/custom receivers must follow [core migration](../../migrations/economics-core.md)
before a connected write. Legacy canonical/entry files here are thin compatibility sources only,
not a second algorithm or opt-in requirement. Preserve previous immutable sources/receipts,
custom or ambiguous files, selected local forms/cards, all task returns/reports and neighbours.
Refuse unresolved dependent replacement before writes; never silently retire a custom alias.
Exact source/target hashes, authority and actions belong in the existing setup/update result.
One immutable payload supplies all changed dependencies; repeat is stable and native behavior
is reported separately from copied bytes. Public home tariff observations/used task quotes are
not generic framework payload and are never replaced by install/update.
