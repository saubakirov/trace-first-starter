## Classify before any connected write

Read current receiving instructions, selected entries/forms and prior installation/update provenance.
Compare each destination's before-image to the verified previous immutable source and proposed
new source. Classify absent, package-owned, project-selected local form, customized or ambiguous;
record hashes, authority, intended action and reason in the existing result/receipt. Mere existence
or an unrelated custom skill is not opt-in or ownership proof. Verify already-equal rows explicitly.

Custom/ambiguous canonical skill, discovery entry or unresolved shared numeric dependency refuses
the whole dependent connected group before writes. A project-customized rate card is preserved;
proceed only if current authority explicitly selects it as a compatible dependency, reporting its
actual epoch/hash and PRESERVED status. Likewise retain an explicitly selected compatible Daily
form/split; incompatible/unresolved forms refuse Daily. A preserved file is never claimed to match
upstream. Resolve an actual missing choice with the receiving owner; repeat no already supplied gate.

Preserve original task JSONL/revisions, report history, selected records and unrelated neighbors.
Schema/rate changes never migrate historical facts. Where multiple selected packages share a
dependency, classify it once and stop every dependent group on refusal; independent Full groups may
proceed. Exclude both extensions and discovery targets from generic payload/adapter overwrites.

## Apply and verify

Apply accepted canonical/source/dependency rows from the single pinned tree and only selected
discovery entries. Updates retain verified selected adapters; a new adapter requires opt-in.
Use existing preservation attachments/immutable update receipts for authorized replacement; never
infer authority from a package version. Verify exact source/target bytes at the actual receiving
root, canonical path resolution, unchanged ten-command/role set, before-image preservation and a
repeat with no unintended diff. Refusal leaves the entire connected before-image unchanged.

Report absent/installed, source presence, filesystem parity/reproduction, complete native load and
later behavior separately. An unavailable Claude host remains unproved even if its entry matches.
Actual native invocation requires a live selected route, not a script copying files. Include
applied/preserved/refused paths, shared dependencies, source coherence, checks and remaining authority
in the existing setup/update result. No production receiver update is implied by local proof.
