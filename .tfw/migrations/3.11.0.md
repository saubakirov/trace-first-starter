# Updating to TFW 3.11.0

This release adds an on-demand feedback skill. The contributor can invoke it in the affected chat and decide whether to share the draft with the TFW maintainer.

| Installed version | Update route |
|---|---|
| 3.10.1 | Pin `v3.11.0` from the configured TFW upstream and verify the target version. Apply the [target update workflow](../workflows/update.md) and the steps below. |
| Earlier supported tag | Follow [3.10.1 and its predecessor routes](3.10.1.md) in order. Apply the selected final payload once. |
| Already 3.11.0 | Recheck the exact pin, selected files, receipt and any unfinished group. Identical verified bytes require no write. |
| Unknown, unsupported or conflicting provenance | Preserve the receiver and resolve its actual source and prior obligations before changing affected files. |

1. Before any generic write, reserve the canonical Feedback path and both discovery paths. Use the [init classification and installation procedure](../workflows/init.md#feedback-prewrite-and-installation) from the same pin. Include the canonical source for direct use. Codex and Antigravity share one discovery entry; include the Claude entry when Claude Code is selected.
2. Verify existing bytes and prior ownership for the whole selected group. On an unresolved customization preserve the group and disclose the conflicting path. If interrupted, recheck completed and outstanding entries against the pin. Keep unselected skills, project state, configured GOAL bounds, Daily choices and history.
3. Compare the source and selected entries byte-for-byte, verify a repeat needs no writes and record the result in the normal receipt. The formal command manifest and briefing template retain their existing formats. No new configuration key or task conversion is needed.
4. In the affected chat, ask “Use tfw-feedback to investigate the last accounting failure” or read `.tfw/extensions/feedback/SKILL.md` directly. File verification covers installation. A native catalog observation establishes discovery only for the client exercised.
