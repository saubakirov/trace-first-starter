# Updating to TFW 3.8.1

This patch release makes `/tfw-economics` a standard workflow for product-oriented resource
analysis, introduces shared public quote history and adds cumulative capture to selected Daily
work. It changes no task-state or numeric v1 schema, formal role, routing field or provider
capability. Installation does not reopen frozen approvals, completed tasks or historical reports.

## 3. Apply changed behavior without rewriting existing authority

| Retired wording / behavior | 3.8.1 successor |
|---|---|
| 3.8.0 guide: "do not install absent adapters or change the ten-command Full set" | Keep actual adapter selection; the standard manifest now contains eleven commands, including `/tfw-economics`. There are still four formal roles. Standalone analysis uses Coordinator scope; task-bound analysis preserves the active role, authority and sole return route. |
| Optional `.tfw/extensions/economics/` as the analysis entry | `.tfw/workflows/economics.md` is the sole canonical analysis workflow. Legacy extension files are compatibility guidance; transition verified old entries through `economics-core.md`, without a competing implementation. |
| 3.8.0 economics contract: "Report prices are conditional Standard API equivalents from rates.json at its dated epoch" | Preserve that original recorded basis. For new valuation, agents acquire official exact-model/profile prices when required, keep dated public observations and copy the actually used basis into the selected task. Money remains an API equivalent with disclosed conditions, not a subscription invoice. |
| Daily work without a cumulative economics return obligation | Selected Daily work captures a validated cumulative snapshot before every orderly turn return and a final snapshot/concise summary at completion. Preserve prior revisions, failures and the last good measurement; never reconstruct a missed historical snapshot as if it existed then. |

The shared home store is `~/.tfw/rates/<provider>/YYYY-MM.json`, keyed by observation month.
Reuse an exact model/profile quote checked strictly less than 30 days ago, including across month
boundaries. Missing model/conditions, expiry or explicit verification for today requires a bounded
first-party lookup by the agent. A token-counter change alone requires no new lookup. Retain older
observations/months; do not create a full provider catalogue, background updater or account service.

Used quotes are immutable task-owned bases. Original numeric v1 returns and compatible historical
cards survive unchanged. Distinguish recorded-basis valuation, evidenced historical reconstruction,
current revaluation and last-known-source failure. Unknown effective dates or request conditions
remain unknown; named conditional scenarios do not establish the actual historical bill. A fresh
quote is not evidence that the same price applied a year ago. The helper validates/stores locally;
ordinary TFW still requires no interpreter and a missing extractor returns a truthful failure.

The report leads with an executive conclusion, product domains/features/keywords and accepted
results, then numeric detail, grounded observations, improvement actions and coverage. Overlapping
keywords select a deduplicated union; they do not multiply cost or prove feature ROI. Tables and
prose carry the complete report. Graphs are optional; requested PDF exports and temporary analysis
scripts go outside the repository to OS temp. Existing Full own-source/return duties stay intact.

Adopt changed instructions at the next authorized activation/resumption of continued work. Preserve
frozen HL/TS and existing routes; a material scope change uses their ordinary amendment authority.
Completed tasks need no retroactive capture. Optional Daily selection grants no Full role or release.
