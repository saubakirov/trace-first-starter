## 2. Install per-launch model and reasoning selection

Refresh `.tfw/conventions.md` and `.tfw/workflows/plan.md` together. Before every actual role launch,
the Coordinator now:

1. checks context, tools, authority, addressability and return prerequisites;
2. sets the required quality floor from uncertainty, dependencies, assurance and consequence;
3. selects model and reasoning effort separately from currently verified native options;
4. records a plausible lower-resource alternative and its material risk or `not compared`;
5. applies native parameters when supported, otherwise emits the exact two-line `Launch` / `Why`
   advice for the owner.

Provider rosters and control syntax stay in the owning adapter or live native inspection, not the
core convention. Requested settings, observable effective settings, delivery, outcome and material
rework remain separate evidence; do not infer minimum sufficiency from completion alone.

This is additive. It supersedes no provider-specific launch command because the previous core had no
per-launch selection contract.

## 3. Restore coordination isolation and research ownership

Refresh `.tfw/conventions.md`, `.tfw/workflows/research/base.md` and `.tfw/glossary.md` as one group.
The canonical heading remains `Workflow activation and routing`. Preserve journal-first context,
all five routing fields, actual unit/address/parent, legacy-absence refusal, exact
`coordination_authority`, proposer and continuation provenance.

Under `tfw-gates-only`, monitor another unit only through addressed TFW messages, bounded provider
status/wait signals and durable returns. Do not inspect foreign transcripts, raw provider-wide state,
session logs, terminals, unreturned worktrees or unrelated task/chat history. One suspected stall
permits one addressed status request, not a short polling loop or relay of unreturned reasoning.

For pipeline research, the Coordinator alone creates and updates `research/iterations.yaml`. Before
each dispatch it prepares one complete pending entry with decision-linked focus, hypotheses, status
and expected RES. The Researcher reads but never creates or edits the control file and returns an
incomplete or missing pipeline entry to the Coordinator.

The retired path text was `.agents/workflows/tfw-{command}.md`. Its successor is
`.agents/skills/tfw-{command}/SKILL.md`; do not recreate the retired directory.
