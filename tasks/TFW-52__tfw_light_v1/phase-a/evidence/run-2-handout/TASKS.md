# Задачи проекта

Этот файл — короткая карта текущей работы. ИИ ведёт её сам: добавляет задачи, меняет статусы и связывает строки с рабочими папками.

## Статусы

| Статус | Значение |
|---|---|
| `НОВАЯ` | Задача зафиксирована, работа ещё не началась |
| `В РАБОТЕ` | Создан `TRACE.md`, идёт работа |
| `НА ПРОВЕРКЕ` | Результат готов и ожидает проверки или решения пользователя |
| `ГОТОВО` | Результат проверен, след и память обновлены |
| `ЗАБЛОКИРОВАНО` | Названо конкретное внешнее препятствие |

## Список

| ID | Задача | Статус | Рабочая папка | Следующий шаг |
|---|---|---|---|---|
| T-001 | Подготовить русскоязычный раздаточный материал по проверке утверждений | `ГОТОВО` | `work/T-001__razdatochnyi-material/` | Обязательных действий нет; материал готов к использованию |

## Правила ведения

- Одна строка соответствует одной проверяемой задаче с конкретным результатом.
- В норме одновременно выполняется одна основная задача.
- Статус меняется сразу при фактическом переходе, а не задним числом.
- Для `НА ПРОВЕРКЕ` указывается, что именно должен проверить или решить пользователь.
- Для `ЗАБЛОКИРОВАНО` указывается недостающий материал, доступ или решение.
- Для `ГОТОВО` рабочая папка содержит заполненный `TRACE.md` и ссылки на все результаты.
