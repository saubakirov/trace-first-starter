# Память проекта

**Состояние:** ИНИЦИАЛИЗИРОВАН

## Карточка проекта

| Поле | Текущее состояние |
|---|---|
| Название | Раздаточный материал по проверке утверждений |
| Активная редакция | TFW Light |
| Версия редакции | 1.0.0 |
| Цель | За 20 минут научить начинающего студента различать факт источника, вывод и предположение, указывать локатор и явно обозначать неизвестное |
| Для кого создаются результаты | Студенты первого курса по государственному управлению, ранее не изучавшие методы проверки источников |
| Признаки полезного результата | После работы с материалом студент классифицирует шесть коротких утверждений и объясняет, как проверить хотя бы одно из них |
| Основной язык | Русский |
| Существенные ограничения | Опора только на предоставленные материалы; внешние факты не добавляются; неизвестное не подменяется догадкой |

## Люди и роли

Здесь фиксируются только сведения, нужные для совместной работы: имя или удобное обращение, роль в проекте, ответственность и потребность в результате.

| Человек или группа | Роль | Что важно учитывать |
|---|---|---|
| Алексей | Преподаватель вводного курса | Нужен готовый к использованию материал для 20-минутного занятия |
| Студенты первого курса | Пользователи раздаточного материала | Нет предварительной подготовки по проверке источников; нужны простой язык и возможность самопроверки |
| ИИ | Методист и редактор учебных материалов | Сохраняет смысловые ограничения источника и проверяет пригодность результата для начинающих |

## Рабочие договорённости

- Результаты создаются на русском языке и должны быть самостоятельными материалами для студента, а не рекомендациями преподавателю.
- Существенные утверждения должны быть прослеживаемы до предоставленного источника; внешние факты не используются.
- Факт источника, вывод и предположение обозначаются раздельно; пробелы и ограничения показываются явно.

## Правило памяти

Память — не архив чата и не склад всех найденных сведений. Она содержит минимальный устойчивый контекст: кто участвует, зачем существует проект, какие правила действуют, что уже подтверждено и почему были приняты ключевые решения. Факт, вывод и предположение всегда обозначаются отдельно.
