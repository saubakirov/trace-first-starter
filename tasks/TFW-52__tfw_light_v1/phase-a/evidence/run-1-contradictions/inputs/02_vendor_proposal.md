# Предложение поставщика по внедрению

## 1. Охват работ

Поставщик настроит единый реестр для финансового отдела, отдела закупок и кадровой службы. В пилотный набор включаются карточки сотрудников, необходимые для согласования заявок, а также справочники поставщиков, заявки и бюджетные лимиты.

## 2. Календарь

Поставщик передаёт настроенную систему 25 сентября 2026 года. Плановая дата открытия производственного доступа — 15 октября 2026 года.

## 3. Приёмка

До открытия производственного доступа поставщик передаёт отчёт руководящему комитету. Запуск выполняется только после зафиксированного решения комитета.
