# Устав проекта «Единый реестр закупок»

## 1. Границы пилота

Пилот охватывает процессы финансового отдела и отдела закупок. Кадровые сведения сотрудников и клиентские записи в пилот не входят. Рабочая группа использует только справочники поставщиков, заявки на закупку и сведения о бюджетных лимитах.

## 2. Календарь

Проверка данных завершается 20 сентября 2026 года. Производственный доступ должен быть открыт 1 октября 2026 года.

## 3. Решение о запуске

Производственный доступ открывается только после решения руководящего комитета. Протокол решения хранится у секретаря проекта.
