# Дополнение по защите информации

## 1. Допустимые данные

В среде пилота разрешены справочники поставщиков, заявки на закупку и сведения о бюджетных лимитах. Кадровые сведения сотрудников и клиентские записи запрещено загружать в пилотную среду.

## 2. Доступ

До решения руководящего комитета допускается только тестовый доступ рабочей группы. Производственный доступ открывается после утверждения комитетом.

## 3. Контроль

Ответственный за безопасность сверяет перечень наборов данных до первой загрузки и фиксирует результат проверки в журнале проекта.
