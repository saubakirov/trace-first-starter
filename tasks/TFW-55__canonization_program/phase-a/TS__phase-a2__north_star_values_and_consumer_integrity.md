### Disposition semantics

- `EXPLICIT RESTORE` means the value/outcome is visibly named in the current canonical essay.
- `SEMANTIC MERGE` means the invariant survives in an identified current clause; the ledger must prove equivalence and losslessness.
- `INTENTIONAL RETIRE` means the old wording conflicts with the current North Star or evidence boundary; the ledger names the conflict and any bounded replacement.
- Do not infer a fourth state such as “already implied.” Implication without a target and reason is the silent-loss defect.

### Dirty-state integration

- Capture before editing; compare again immediately before RF.
- Edit source workflows first, then synchronize their installed copies with the repository's full-copy rule.
- Apply hunk-level changes to the latest TFW-60 master. Never restore that file from the planning snapshot.
- Stage only explicit Phase A.2 paths. If an in-scope file has a foreign overlapping hunk whose owner cannot be distinguished, stop and escalate rather than choosing ownership.
- The existing `.tfw/README.md` image insertion is input, not Phase A.2 authorship.

### North Star editing boundary

- Preserve the current narrative, definition, human/agent boundary, NS1–NS3, proportional realization section, and authority routing.
- The 2,645-word measured planning headroom is safety margin, not an allocation target. Prefer semantic merge and precise naming; add only necessary meaning and never expand merely because capacity exists.
- If the bounded dispositions cannot fit coherently within 4,200 words, stop and return for a new owner-approved amendment; delegated authority cannot accept the overrun.

### Active consumer versus history

- Current framework instructions/templates/glossary and the current active TFW-60 master are consumers.
- Completed task traces and changelog entries are historical evidence. They may contain retired strings and must not be normalized.
- KNOWLEDGE D44/current task index and TD-166 are current indexes, but their correction belongs after REVIEW under `/tfw-docs`/debt closure, not the Executor diff.
