## 5. Risks Found (edge cases, potential issues not in TS)

1. Several owner-source sentences are intentionally stronger than the approved contract: deterministic reproduction, total pre-delegation understanding, observability as trust, and absolute memory ownership all require qualification.
2. The current essay contains historical absolutes about regenerated code, self-maintaining documentation, one deterministic lifecycle, the same artifacts in every domain, lossless context, and output needing no manual editing. Retaining them would fail AC-2, AC-3, AC-5, or AC-6.
3. The working BoK contains a maturity model, hypotheses, open questions, candidate practices, and unresolved contradictions. It may check completeness but cannot supply canonical assertions or a Phase A outline.
4. Directory and anchor links can appear plausible while remaining renderer-dependent or broken. EV must resolve every local target and check the three literal IDs.
5. Pre-existing dirty TFW-54 and TFW-55 research/tmp paths share the checkout. All staging must name only Phase A-approved paths.
