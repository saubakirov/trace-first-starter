## Findings

### E1 — Corpus and selector are separate functions in every viable authority model

The central D2 mistake is to make one thing do two jobs:

- **corpus function:** retain primary traces, evidence, superseded decisions, rejected experiments, and evolution;
- **selector function:** tell a reader or agent what TFW officially means and how it operates now.

The repository can perform the corpus function under every configuration. What changes is the selector.

| Config | What preserves history/evidence? | What selects current official meaning? | What selects current operational mechanics? |
|---|---|---|---|
| C1 | Repository corpus + Git | Canonical essay | Living specification |
| C2 | Repository corpus + Git | Canonical philosophical text shared by essay/spec | Living specification interpreted through that text |
| C3 | Repository corpus + Git | Canonical methodology essay | Living specification |
| C4 | Repository corpus + Git | Explanatory essay, without a new-category claim | Living specification |
| C5 | Repository corpus + Git | Living specification itself | Same living specification |
| C6 | Repository corpus + Git | The corpus, resolved by current branch/state and internal links | Current files in the corpus; no separate selector |
| C7 | Repository corpus + Git | Separate minimal canon/guide | Living specification |
| C8 | Repository corpus + Git | Root README | Living specification |
| C9 | Repository corpus + Git | Canonical essay; operational six-question check remains in spec | Living specification |

The 53-commit TFW-48/49 episode does not decide whether TFW is a philosophy. It proves three narrower points that all configurations must handle:

1. the corpus can preserve a rejected experiment and an explicit restoration without erasing history;
2. the current branch/tree can recover operational authority after over-engineering;
3. a corpus without a selector forces readers to infer whether an old frozen HL, an approved-but-reverted RF/REVIEW, a restoration commit, or the current specification is authoritative.

The narrow external control strengthens the separation without prescribing an imitation. [Scrum Guides](https://scrumguides.org/download.html) explicitly names one English guide/version as the current official definition, labels translations by version, and sends readers elsewhere for revision history. Its [revision history](https://scrumguides.org/revisions.html) preserves changes and explains why the 2020 text became less prescriptive and less IT-specific. This is one mature example where selected current meaning, translations, and history have distinct roles. It does **not** prove that TFW needs Scrum's governance, a separate BoK, or an immutable definition.

### E2 — Category and implementation are independent dimensions

The Configuration Space exposes a pattern hidden by the Briefing's “fundamental philosophy vs framework” debate:

- C1 and C6 use **discipline** but radically different authority systems.
- C3 and C9 use **methodology** while one retains the public self-awareness label and Editions example and the other removes both.
- C4 makes no higher-category claim yet preserves the same layered corpus/essay/spec architecture as C1.
- C2 is philosophy-led but may require a larger trace assurance chain than C1.
- C5 is framework-led and collapses meaning/mechanics into one specification.

Therefore the category decision cannot be inferred from current files, number of artifacts, or self-canon structure. H2 remains provisional. W3C/NIST show that components are not novel; only Iteration 2 can test whether the operational composition and scope justify a distinctive category.

### E3 — Trace floor and assurance layers should not be synonymized

Across C1–C9, three compatible roles recur:

```text
selected continuity trace
        ↓ when required by risk or lifecycle
evidence + review
        ↓ after verification/consolidation
verified reusable knowledge
```

This does not yet select C1, C3, C4, or C9. It makes one hidden incompatibility visible: if the essay defines “trace” as the entire assurance chain, Light and ordinary work inherit Full's machinery; if it defines trace as provenance-only, it loses the intent, rejected alternatives, and continuation context that internal evidence treats as important. C9 makes the proportional hybrid explicit: a selected trace is the semantic floor, while evidence/review/verified knowledge remain separately named layers that scale with risk.

The term must continue to exclude raw chat exports and hidden chain-of-thought. A transcript may be a source, and provenance may describe it, but neither automatically becomes a useful project trace.

### E4 — Human-reader versus agent-orientation compatibility test

The test is cross-cutting because humans and agents need different densities without being allowed different meanings.

| Test | Human requirement | Agent requirement | Failure signal |
|---|---|---|---|
| **T1 Identity** | Explain what TFW is/is not without artifact jargon | Resolve category, boundaries, authority, and current task rules | Human and agent give materially different definitions |
| **T2 Start** | Choose a proportional entry and act without reading the whole corpus | Load exact current instructions and relevant traces | Simplification removes needed start information or agent loads marketing instead of rules |
| **T3 Authority** | Know where official meaning, current mechanics, and evidence/history live | Know which source governs conflicts and which files are historical | Corpus, essay, and spec can contradict with no precedence |
| **T4 Load budget** | Root ≤800 words; essay ≤2,000 words; link outward | Progressive disclosure; task-local context before unrelated corpus | One “universal” text becomes too vague for action or too long for orientation |

D9 Alt B is the only configuration pattern that explicitly optimizes both audiences while demanding semantic parity; that is an analytical pattern, not yet a recommendation. Alt A, C, and D remain viable until Challenge tests load, drift, and authority.

### E5 — Teaching states remain separate under every configuration

| State | What the corpus contains | Permitted interpretation in Iteration 1 | Not permitted |
|---|---|---|---|
| **Teaching observation** | Day-1 folder confusion after practice was squeezed; Day-2 starter/practice “worked normally” without tests; Day-3 manifesto discussion; university Day-2 artifacts were more concrete with participant attrition | A dated, founder-led observation about this material/audience | General learning efficacy, causal effect, or independent facilitation |
| **Proposed pedagogical mechanism** | useful work → visible insufficiency → add context/mechanism → compare attempts → name principle; delayed recall and transfer gates designed later | A falsifiable mechanism and design candidate | A demonstrated universal sequence |
| **Demonstrated learning outcome** | Immediate artifacts and speaker/owner acceptance; no delayed unfamiliar-task transfer or independent-facilitator result in the selected corpus | Immediate artifact completion only where recorded | Durable “mindshift,” transfer, retention, or causal superiority |

This separation changes configuration routing:

- an invariant or boundary may enter the essay after Challenge;
- an owner interpretation remains sourced as such;
- a pedagogical mechanism belongs primarily in the future guide/course unless it explains an essential method boundary;
- a teaching observation stays in research/evidence;
- a demonstrated learning claim requires the assessment gate actually to have run.

C1/C3 may mention the Editions path as a bounded example. C2/C5/C8/C9 can omit it from the foundation without denying the teaching observations. C7 can make it central to the guide without promoting it to a universal philosophical truth.

### E7 — Candidate invariants for Challenge, not decisions

The following recur across multiple otherwise different configurations. Challenge must test rather than assume them:

1. **Corpus ≠ selector:** history/evidence preservation and current official meaning are separate functions.
2. **Principle ≠ mechanism:** current artifacts may implement a principle but cannot define the principle by themselves.
3. **Trace ≠ transcript/hidden reasoning:** a trace is selected, durable, inspectable project memory with provenance; assurance layers remain distinct.
4. **Delegation ≠ authority creation:** a role or task assignment can bound authority but cannot manufacture owner legitimacy or independent identity.
5. **Capture ≠ verified knowledge:** work may generate candidates by design; maintenance, review, and consolidation remain real actions.
6. **Teaching observation ≠ mechanism ≠ outcome:** each has a separate evidence threshold and destination.
7. **Edition path ≠ universal maturity ladder:** current proportional implementations and founder-led pedagogy do not establish one path for all users.
8. **Human/agent density may differ; semantics may not:** different entry points require a parity/precedence rule.
9. **Rejection is part of self-description:** a self-applying corpus must retain rejected paths without making them current authority.

### E8 — Unexpected configuration revealed

**C9 Quiet semantics** was not proposed in the Briefing. It separates memorable claims from operational capability:

- keeps the layered self-canon architecture and a methodology-level category;
- retains the six-question self-description test in the living specification;
- does not use “self-aware project” as the public identity phrase;
- defines selected trace as the floor and assurance layers as proportional additions;
- omits Editions from the canonical essay while leaving them in usage and teaching surfaces;
- gives humans and agents different entry points under one semantic-parity contract.

This combination matters because it shows that H1/H4 can survive even if the owner-preferred self-awareness label and Light → Assisted → Full essay bridge do not. Challenge must compare it with C1, C3, and C4 rather than treating label rejection as architecture rejection.

### E9 — OODA orientation and Extract decisions

**Observe.** Nine configurations cover philosophy-, discipline-, methodology-, framework-, specification-, corpus-, guide-, one-surface-, and quiet-semantics models. D9 exposes a cross-audience decision omitted from Gather.

**Orient.** The major dependencies are not “more philosophy means more files.” Category (D1), authority (D2), trace floor (D3), public label (D4), and delivery surfaces (D6/D9) can move separately. That is why the framework-only challenger and the layered self-canon can share most architecture while disagreeing on identity.

**Decide.** Extract is sufficient for focused mode: the Configuration Space contains all Gather dimensions plus justified D9; corpus/selector roles are explicit; the human/agent test is operational; teaching evidence states are separated; and C9 is an unanticipated viable combination. No configuration has been eliminated.

**Act.** Carry C1–C9, invariants I1–I9, the H1–H4 map, and the exact C4 challenger into Challenge. Challenge should use pairwise consistency and falsification against frozen DoD/DoF, source evidence, authority resolution, claim calibration, human/agent compatibility, and over-engineering cost.
