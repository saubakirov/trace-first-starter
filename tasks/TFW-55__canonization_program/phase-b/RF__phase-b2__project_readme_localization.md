1. **Function governed restoration.** Every historic heading was kept. Sentences changed only for current facts, authority, stale navigation, Edition/command/path mechanics, or minimal Philosophy-of-Trace alignment.
2. **English was reconstructed as two regions.** Only the public prefix came from `b924926`; the Task Board came from the exact Executor start commit. No whole historical README restore occurred.
3. **Philosophy stayed bounded.** One practical definition states the methodology, selected Trace, six human responsibilities, and bounded agents. The essay link carries the full argument; no NS1/NS2/NS3 mirror or second essay was added.
4. **Current sources overruled stale prose.** Edition selection/migration, Quick Start, all 11 commands, repository/core structure, adapters, lifecycle/evidence mechanics, update flow, and navigation were checked against their live repository sources.
5. **Localization was independently challenged.** Separate read-only RU and KK critics read the exact frozen Git objects. All 22 draft findings were fixed; the same critics then re-read exact production commit `5d7edc0` and accepted both blobs with unresolved HIGH 0.
6. **Taste did not create an endless loop.** The new exact-final KK-F-L1 observation is LOW, changes no meaning or function, and was explicitly accepted by the critic without reopening the accepted blob.
7. **The old chain remains visible as superseded.** [Old B1 RF](RF__phase-b__multilingual_public_entry.md) and [old B1 REVIEW](REVIEW__phase-b__multilingual_public_entry.md) are unchanged. Their APPROVE verified the wrong compact-doorway function and was superseded by owner rejection.
