# TFW Light

> **Работа должна оставлять след.** Ответ исчезает в чате. Цель, источники, решения и знания остаются в проекте.

## Идея

TFW Light — простая дисциплина совместной работы человека и ИИ. Она нужна, чтобы новый чат, другой ИИ или новый участник мог понять проект и продолжить работу без длинного пересказа.

След — это не стенограмма беседы и не скрытые рассуждения модели. Это короткая полезная запись: зачем выполнялась задача, какую роль взял ИИ, какие материалы изучены, что обнаружено, какие решения приняты, как проверен результат и где он лежит.

Метод подходит для документов, финансов, аналитики, образования, исследований, управления, визуализаций и любых других задач. Специальные программы и команды не нужны: память проекта хранится в обычных Markdown-файлах.

## Структура

```text
README.md             идея, структура и быстрый запуск
AGENTS.md             правила работы для ИИ
TASKS.md              список задач и их состояние
memory/
└─ PROJECT.md         цель проекта, люди, договорённости, знания и решения
work/                 рабочие следы и результаты; создаётся при первой задаче
```

Для каждой задачи ИИ создаёт отдельную папку:

```text
work/T-001__kratkoe-nazvanie/
├─ TRACE.md           цель, источники, находки, решения и проверка
└─ ...                готовые документы, таблицы, презентации, изображения
```

Начальных файлов всего четыре. `work/` и `TRACE.md` появляются только тогда, когда начинается реальная работа.

## Один рабочий ритуал

1. **Понять** — кто пользователь, для кого результат, какова цель и какую профессиональную роль должен взять ИИ.
2. **Зафиксировать** — добавить задачу в `TASKS.md` и создать её `TRACE.md`.
3. **Сделать** — изучить материалы, сохранять существенные находки в файл, подготовить полноценный результат.
4. **Проверить** — сверить результат с целью и источниками, явно показать пробелы и неопределённость.
5. **Сохранить** — обновить статус задачи, оставить пути к результатам и перенести долговечные знания в `memory/PROJECT.md`.

Задача не считается завершённой, пока результат существует только в чате.

## Запуск за минуту

1. Скопируйте содержимое этой папки в корень нового проекта.
2. Откройте проект в ИИ, который умеет читать и изменять файлы.
3. Отправьте сообщение ниже и сразу добавьте свою задачу.

```text
Этот проект работает по TFW Light — простой дисциплине сохранения целей,
источников, решений и знаний. Прочитай по порядку AGENTS.md, README.md,
memory/PROJECT.md и TASKS.md. Если проект ещё не инициализирован, проведи
короткий первый запуск. Затем выполни мою задачу полностью, сохраняя рабочий
след и результат в файлах проекта.

Первая задача: проанализируй приложенные документы, найди противоречия и
подготовь понятную таблицу со ссылками на конкретные файлы и страницы.
```

Формулировку последнего абзаца можно заменить своей задачей. Всё остальное ИИ ведёт сам: задаёт только необходимые вопросы, создаёт папку работы, обновляет список задач и память проекта.

## Главные правила

- Факты, выводы и предположения не смешиваются.
- Для важных утверждений указывается источник: файл, страница, раздел, таблица или расчёт.
- Неизвестное обозначается честно; отсутствующие данные не выдумываются.
- Пользователь не обязан вручную копировать журнал или поддерживать структуру.
- В память попадает только то, что поможет принимать решения в следующих задачах.
- Результат должен быть готов к использованию, а не оставлен как заготовка «на потом».
