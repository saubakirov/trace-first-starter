# Профили участников

Один человек — один файл `people/<handle>.md`. Имя файла содержит короткий стабильный handle из латинских букв, цифр, `_` или `-`; `README.md` профилем не считается.

Минимальный профиль содержит:

- `Идентификатор: <handle>`;
- `Отображаемое имя: <имя>`;
- `Тип: человек`.

Для автоматизации используйте отдельный профиль с `Тип: automation` и идентификатором `automation:<имя>`. Автоматизация не заимствует имя человека.

Если профиль один, Codex использует его без вопроса. При нескольких профилях выбор хранится только на личном устройстве; общего файла текущего пользователя в проекте нет. На новом, общем, скопированном или несовпадающем устройстве Codex задаёт один короткий вопрос перед первой записью авторства. Чтение и обычный разговор выбора не требуют.

Профиль — заявленная атрибуция и происхождение записи. Он не аутентифицирует человека и не подтверждает полномочия.
