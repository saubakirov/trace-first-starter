# Карта памяти проекта

Этот файл — короткая навигация, а не вторая копия фактов.

- `records/` содержит проверенные долговечные записи проекта. Нейтральный starter не поставляет готовых фактов: записи появляются только из подтверждённой работы.
- `inbox/` содержит независимые кандидаты знаний с источником, автором и проверкой риска. Создаётся при первом использовании.
- Первичным источником остаётся `TRACE.md` задачи; создание кандидата его не переписывает.

## Что уже лежит в `records/`: пустое начальное состояние
Проверенных записей пока нет; это ожидаемое состояние нового проекта.
| Состояние | Что делать | Когда перепроверить |
|:---|:---|:---|
| Пусто | Не придумывать стартовые факты | Перед первой долговечной записью |
| Новый кандидат | Сначала сохранить источник и автора | До переноса в `records/` |
| Проверенная запись | Добавить её отдельным решением | При изменении предметной области |
| Рискованный материал | Остановиться и запросить человеческое решение | До общей записи |
Заполняйте `records/` только проверенными сведениями, которые действительно относятся к этому проекту.
Нейтральный пакет не содержит предварительно заполненных фактов, людей, целей или организационных утверждений.

В Assisted нет автоматической консолидации, продвижения кандидатов, обновления этого индекса, чистки или дедупликации. Автономная оркестрация задач не даёт таких полномочий: любое подтверждение и изменение карты выполняется как отдельная явно порученная работа с собственным следом, а решение о знании должно быть фактически завершено до финальной приёмки задачи.

Секреты не записываются. Медицинские, персональные, юридические, финансовые и иные чувствительные сведения удерживаются до явного подтверждения; при сомнении материал не публикуется.
