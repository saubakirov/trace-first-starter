# Карта памяти проекта

Этот файл — короткая навигация, а не вторая копия фактов.

- `inbox/` содержит независимые кандидаты знаний с источником, автором и проверкой риска.
- `records/` предназначен для отдельно подтверждённых долговечных записей.
- Первичным источником остаётся `TRACE.md` задачи; создание кандидата его не переписывает.

В Assisted нет автоматической консолидации, продвижения кандидатов, обновления этого индекса, чистки или дедупликации. Папки `inbox/` и `records/` создаются при первом использовании. Любое подтверждение и изменение карты выполняется как отдельная явно порученная работа с собственным следом.

Секреты не записываются. Медицинские, персональные, юридические, финансовые и иные чувствительные сведения удерживаются до явного подтверждения; при сомнении материал не публикуется.
