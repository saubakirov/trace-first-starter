# Карта памяти проекта

Этот файл — навигация, а не вторая копия фактов. Стартовый пакет не содержит записей о какой-либо организации, проекте или человеке.

- `inbox/` создаётся при первом подтверждённом кандидате знания. Кандидат содержит утверждение, источник, автора, область применимости и проверку риска.
- `records/` создаётся при первом явно продвинутом долговечном знании. Одна проверяемая тема — один файл.
- Первичным источником остаётся `work/<ID>/TRACE.md`; кандидат или запись его не переписывают.

До человеческой приёмки задачи для каждого кандидата фиксируется решение:

- `promote` — создать или обновить отдельную проверяемую запись;
- `retain in trace` — оставить только в следе задачи;
- `reject` — не переносить в долговечную память.

Assisted не выполняет автоматическую консолидацию, продвижение, обновление этого индекса, очистку или дедупликацию. Секреты не записываются; чувствительные сведения удерживаются до отдельного явного подтверждения.
