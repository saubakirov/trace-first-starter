# Проект

Активная редакция: Assisted
Версия редакции: 1.0

## Цель

Создавать проверяемые результаты по повторяющимся задачам и сохранять достаточно контекста, чтобы следующая сессия продолжала работу без пересказа чата.

## Образ полезного результата

- результат доступен по явному пути;
- критерии и проверка записаны до завершения;
- решения и ограничения можно восстановить из task-local trace;
- долговечные знания отделены от временного контекста.

## Участники

Профили людей хранятся отдельными файлами в `people/`. Один профиль выбирается без вопроса; при нескольких выбор привязывается только к личному устройству. Автоматизация использует отдельный ID `automation:<имя>`. Профиль сообщает заявленного автора записи, но не подтверждает личность или полномочия.

## Ограничения

- Секреты не записываются в проект.
- Чувствительные сведения не переходят в общую память без явного подтверждения.
- Одну задачу и один изменяемый trace ведёт один владелец записи.
- Одновременное редактирование одного общего файла не считается безопасным.
- Периодическая консолидация памяти и организационные режимы не входят в эту редакцию.
