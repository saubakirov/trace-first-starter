## 1. Objective

Retire the project-level tech debt registry. `TECH_DEBT.md` leaves the project root and is sealed verbatim
beside the retired Task Board; the canon stops instructing anyone to append to a shared list; and a review
disposes of every item it captures — paid as a phase, promoted to a task, or ruled not material — before
its task can close. Receiving projects get prose that lets their own agent do the same move, carrying the
reason and not only the steps. Nothing is created to replace the registry: the net count of maintained
project artifacts falls by one.

## 2. Scope

### In Scope

- Deleting `TECH_DEBT.md` from the root of **this** repository and sealing it as `tasks/DEBT-SNAPSHOT.md`.
- Every canonical surface that writes, reads, installs or names the registry: conventions, glossary,
  workflows, templates, the compilation contract, all three adapter sets and both marker blocks.
- The disposition gate in `review.md`, and the removal of any canonical sentence that offers deferral as a
  way to finish incomplete work.
- A retirement instruction in `.tfw/migrations/2.0.0.md` for receiving projects, including the safety
  exception routed through a question to the user.
- The documentation build and its tests, so `TD-N` citations keep resolving.
- Release as the next version of the 2.x line.

### Out of Scope

- **Performing the retirement in any other project.** Other projects' registries are their own. This task
  writes the instruction and never edits a receiving tree, never triages a receiving registry, and never
  rescues anything from one. Reading a sibling registry to test the prose is permitted and is read-only.
- **Reading, scoring or triaging this repository's 121 rows.** Forbidden by amendment A1 and by DoD 13.
  Not a preference — an executor that opens the rows to decide anything has failed the task.
- Deleting `resume.md`. The owner ruled it obsolete on 2026-09-01; that is a separate task and this one
  only stops it reading a file that no longer exists.
- `README.md` and `KNOWLEDGE.md` growth control — `PROPOSAL__TFW-57` still stands for those two.
- Task-local knowledge staging. Dropped with TFW-60 Phase C, not reopened.
- Any new file, template, script, check or configuration key. Adding one fails the task (DoF 5).

## 6. Technical Guidance

- **The precedent is five days old and is the model to copy.** `tasks/BOARD-SNAPSHOT.md` retired the root
  Task Board at 2.0.0: 158 lines, 61 rows, header declaring history, and the rule that replaced it —
  *"An idea is picked up by creating a real task, not by resurrecting a row."* Read it before writing the
  snapshot header. The retirement of a registry should look like the retirement of a board.
- **Where the destination rule lives:** `migrate_board.py` `legacy_container()` — *"the last configured
  container, which holds the old corpus."* It resolves to `tasks/` here. For receiving prose, name `tasks/`
  directly; the rule and the measurement agree in every project measured, and only the measurement can be
  followed by a project that has not yet migrated.
- **The two workflows that read the registry today** are `docs.md` prerequisite 2 and `resume.md` step 9,
  and `resume.md`'s anti-pattern list at lines 112–113 *obliges* acting on what step 9 read. All three
  places go. `resume.md` itself stays for now.
- **The five field reports in `tasks/TFW-60__conflict_resistant_shared_workspace/`** are the evidence base
  for how receiving agents actually behave with prose. The fifth is the most useful: it records an agent
  setting two config keys and inferring an identity from the git author, purely because the text implied
  those decisions without gating them.
- **`review.md` Step 5 already contains a quality filter** — *"reject filler observations; only promote
  items that would cause real problems if left unfixed"* — and the file grew eightfold with it in force.
  Do not solve anything by strengthening that sentence.
- **Content language is `en`** for artifact content (`tfw.content_language`).

## 7. Definition of Failure

- ❌ Any row is deleted, renumbered, re-sorted or reworded during the seal.
- ❌ The executor reads the 121 rows to decide anything about them. A1 forbids it and no result justifies it.
- ❌ Any file in any project other than this one is created, modified, moved or deleted.
- ❌ A `TD-N` citation stops resolving, or a redirect layer is introduced to keep it resolving.
- ❌ Anything new is introduced that must be maintained — a file, template, script, check or config key.
- ❌ A receiving instruction requires running a command, a script or a check.
- ❌ Any surface is left naming a live registry after the release — an adapter copy, a marker block, a
  template or a translated README included.
- ❌ Deferral survives anywhere in the canon as a legitimate way to finish incomplete work.
- ❌ The disposition gate ships as a new artifact or a new configuration key rather than as prose.
- ❌ The scope budget is exceeded without stopping and reporting first.
