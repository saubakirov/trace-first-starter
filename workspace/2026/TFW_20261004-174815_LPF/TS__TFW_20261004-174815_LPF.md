## 1. Objective

Deliver TFW rules under which a project holds only its result and its selected trace:

- working material — raw output, logs, exports, screenshots, archives, copies, helper scripts — lives
  in the system temporary directory under `tfw/<task or record ID>/`, private to the role that made
  it, and is removed when that role's work ends (Closing step 6 as the backstop);
- `evidence/` holds only the EV registry: *verified · how · observed · result*, with deciding values
  captured when the observation is made and an attested form for claims that cannot be repeated;
- a Daily record lists every product with its project path and its folder holds only record and
  economics files before each orderly turn return;
- a comment in a value file carries value for its reader or is read by a program — never a channel;
- every adapter root states both rules in one line that reaches every session;
- receivers get a migration guide that explains the harm of comment correspondence and offers an
  optional cleanup task (now / later / not at all), recorded in the update receipt;
- this repository's live code and configuration carry no non-value comments, and this task's own
  trace is the first instance of the rule.

Value: repositories stop growing from junk — fast clones and updates, searches that find decisions,
agent tokens spent on meaning (HL §1).
