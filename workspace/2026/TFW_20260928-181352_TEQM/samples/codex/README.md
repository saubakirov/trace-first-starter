# Codex — реальные UPM / DARYN

Владелец прямо поручил текущему Координатору проверить числовые показатели соседних сессий UPM или DARYN. Образцы сохраняются здесь в подпапках по задаче. Это разрешение на чтение числовых метаданных и создание образцов; исходные задачи продолжают свою работу.

Привязка начинается с точных ID найденных чатов и путей задач. В отчёт попадают числовые события использования и временные границы; содержимое сообщений и рассуждений не переносится. Итоги привязываются к моменту среза и к реально найденному набору сессий.
