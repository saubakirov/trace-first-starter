## 6. Technical guidance — non-binding implementation choices

The initial single helper path keeps delivery small; it does not require a monolithic architecture. Executor may prospectively request a necessary module split under the accounting rule when that improves inspectability. Shared pure normalization/validation functions and replaceable provider readers are preferable to three independent reporting engines. Keep the selected platform recipe separate from common semantics; readable headings can supply the first version without a plugin system. Python `sqlite3`, `json`, `datetime`, `decimal`, `hashlib` and `csv` cover the demonstrated needs without third-party packages. Streaming numeric extraction can avoid retaining text payloads; never dump a raw event for debugging.

Prefer normalized mutually exclusive token buckets for sums while preserving source inclusion semantics. A duration measured over a whole source run need not be duplicated across each daily/model row. Export it at its known granularity and leave unsupported filtered duration unknown. Do not invent a model/time split from proportional tokens. A source's date gap belongs in an explicit undated bucket outside dated totals, visible in coverage.

Stable source identity plus provable coverage matters more than a sophisticated import engine. A whole-source successor snapshot can replace an earlier one where its prefix/coverage is verified; reject an unprovable overlap rather than building arbitrary event reconciliation. A read-only SQLite backup/snapshot prevents partial reads of changing Antigravity sources. Avoid matching tasks by titles or trusting only the last model in a session database.

Seed the rate card with the observed models only, keeping source URL/effective epoch and pricing qualifications. No live network request is necessary to read an already captured task. New schema versions are deliberate data-contract changes; ordinary TFW updates must not rewrite task history. A later analysis tool can consume CSV/JSONL without becoming another TFW authority.
