Corrected whole-source snapshots replace earlier totals only with a verified prior file and matching native source-prefix hash; disjoint ranges add; ambiguous overlap is excluded and diagnosed. 3. Compact native numeric events to source/day/model/effort totals plus separate duration rows. Native event IDs are checked during extraction and represented only by a count/digest in the routine file. Date-only or undated historical evidence does not gain an invented minute.
4. Keep the helper optional and standard-library only. A diagnosed source change may use the TS-authorized bounded extractor adaptation; unexplained meaning yields a failure receipt. No package installation, service, global scan or hidden role was introduced.
5. Label rates as a 2026-09-29 Standard API scenario. Unknown exact models, tariff splits, storage, tools and subscription allocation stay unpriced rather than guessed.
