## Research Plan

### Gather
- Extract exact current source ranges and word counts for each role/checkpoint, separating always-read instructions, checkpoint-triggered rules, task-variable artifacts, PV reads, lookup-only definitions, and history.
- Inventory every proposed glossary/history deletion line by line and map it to a surviving condition/action/authority statement, structural test, or immutable historical source; flag any sole carrier.
- Reconstruct Knowledge Gate inputs and existing state/candidate surfaces, then replay no-op, threshold, retry, migration, equal-time, candidate/no-candidate, and malformed-source cases against alternative cursors.
- Inventory Codex, Claude Code, Cursor, and Antigravity adapter installation/resolution behavior and the tests that can exercise a clean receiving project without changing shipped code.
- Define baseline/candidate fixtures for decisions, refusals, artifacts, citations, and gates across Coordinator, Researcher, Executor, Reviewer, revision, resume, and knowledge close.

### Extract
- Build a configuration space across range granularity, cursor identity, fixture oracle, history destination, and adapter proof mechanism.
- Select exact per-role source ranges and recompute current-to-candidate exposure with no 3,200-word allowance.
- Select one Knowledge Gate algorithm with explicit state schema, total ordering/deduplication behavior, and replay results for every assigned case.
- Produce a file/section recommendation ledger: current purpose; delete/merge/redirect/reword; proposed wording; reason; and semantic-preservation check.
- Specify clean-context and clean-receiver fixture matrices that are independent from the audit manifest they validate.

### Challenge
- Seek counterexamples in which addressed reads omit a refusal, cross-role invariant, compatibility branch, or enforcement-critical default.
- Attack the selected cursor with equal timestamps, retries, migrated sequence state, candidate-free tasks, duplicate sources, malformed artifacts, and interrupted consolidation.
- Run available repository and receiver-facing adapter checks, and distinguish measured behavior from documentation-only inference for every supported adapter.
- Attempt to falsify H2–H4 and the ≥30% result using the exact range model; reject any recommendation whose semantic check cannot be named.
- Decide whether iteration 2 is sufficient for Coordinator planning or whether a narrowly stated iteration 3 is necessary.
