Six non-substitutable evidence levels
=====================================

R0 source presence: canonical/adapter source exists.
R1 receiver parity: tracked/installed copy matches its declared source.
R2 invocation: runtime trace shows the command receiver was invoked.
R3 complete load: runtime trace shows the complete canonical workflow was loaded.
R4 later conformance: subsequent reads/writes/gates/stops obey the loaded workflow.
R5 controlled comparative effect: fixed repeated arms establish a bounded difference.

No lower level proves a higher one. Clean-receiver PASS reaches R1 only. The partial Phase-A
JSONL could independently establish allowed artifact/gate outcomes for the seven completed
runs, but its CLI JSON emitted no observable command-execution events for skill/workflow reads;
model self-report was ignored. Therefore it did not establish R2/R3 or R5.
