- **Как запускалось исторически:** Запуск на флагманских моделях с максимальным thinking. Модель тратила 30–60 секунд на ответ, генерируя огромные цепочки рассуждений о том, «правильно ли переводить слово Architecture».
- **Применение правила 3 уровней CMTR:**
  - *Класс:* **Procedural** (Fast tier, Thinking: Low / Off).
  - *Выбор для Antigravity:* `Gemini 3.8 Flash (Thinking: Low)`.
  - *Выбор для Claude / Codex:* `Claude 3.5 Haiku` / `o3-mini (effort: low)`.
  - *Эффект:* Снижение задержки ответа в 8–10 раз (отклик за 3–5 секунд), экономия ~75% токенов, полное отсутствие галлюцинаций overthinking.

### G2: Сценарий 2 — Стандартная инженерная реализация по TS (TFW-26 Phase A/B)
- **Суть задачи:** Разработка скрипта генератора документации `gen_docs.py` (445 строк Python), парсинг ссылок, frontmatter, прогон набора из 42 тестов `pytest`.
- **Характер работы:** Написание чистого кода по жестко специфицированным критериям приемки (AC-1..AC-7) в утвержденном TS. Архитектура формата компилируемого контракта уже зафиксирована в `compilable_contract.md`.
- **Как запускалось исторически:** Запуск на стандартной модели без явного управления thinking.
- **Применение правила 3 уровней CMTR:**
  - *Класс:* **Standard** (Balanced tier, Thinking: Medium).
  - *Выбор для Antigravity:* `Gemini 3.8 Pro (Thinking: Low)` или `Claude 3.7 Sonnet (Thinking: Low)`.
  - *Выбор для Claude / Codex:* `Claude 3.7 Sonnet (thinking ~4k)` / `o3-mini (effort: medium)`.
  - *Эффект:* Высокая точность синтаксиса и алгоритмов, удержание взаимосвязей между файлами тестов и скрипта, отсутствие зацикливаний на тривиальном коде.

### G3: Сценарий 3 — Критический состязательный анализ и ревью (TFW_20260921-180000_RVAG)
- **Суть задачи:** Независимый аудит дефектов процесса (кейс MFX), состязательное ревью, доказательство соответствия Project North Star, отклонение необоснованных возвратов.
- **Характер работы:** Глубокая логическая критика, выявление скрытых допущений, преодоление сикофантии (принцип F3). Ошибка или поверхностный апрув стоят срыва всего проекта.
- **Как запускалось исторически:** Использовались тяжелые reasoning-модели (Claude 3.7 Sonnet Extended Thinking, o3).
- **Применение правила 3 уровней CMTR:**
  - *Класс:* **Critical / Adversarial** (Heavy Reasoning tier, Thinking: High / Max).
  - *Выбор для Antigravity:* `Claude 3.7 Sonnet (Thinking: High)` или `Gemini 3.8 Pro (Thinking: High)`.
  - *Выбор для Claude / Codex:* `Claude 3.7 Sonnet (max-thinking 16k+)` / `o3 (effort: high)`.
  - *Эффект:* Бескомпромиссная защита целей проекта, глубокий анализ граничных условий, предотвращение сикофантического одобрения брака.
