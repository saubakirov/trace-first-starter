## Research Plan

### Gather

- Trace one complete happy path and the material exception paths through current task state, journal and role-owned HL/TS/RES/ONB/RF/EV/REVIEW carriers; record each activation, durable return, question, ruling and next-role trigger by owner and write authority.
- Inventory the actual value added by a named principal and persistent LEAD across an owner-only machine, a shared office host, repeated sessions and several humans; keep addressability, attribution, mandate, authority, approval provenance and capability exposure as separate dimensions.
- Reconstruct repository-level mutation, landing and release contention from current worktree/exact-path rules and source traces; distinguish resource ownership from agent/task identity and genuinely read-only parallelism from operations that can invalidate another lane.
- Collect bounded native Codex and Claude evidence for title mutation/readback, task continuation and routing capabilities, plus the current reader/consequence census needed to test compression without rerunning the broad receiver inventory.

### Extract

- Build an activation/dialogue/carrier matrix for the happy path and exceptions, identifying whether an existing owned artifact or state transition can carry every material fact without cross-role authorship or a new carrier.
- Compare four identity configurations—owner-launched role, selected LEAD root, shared-host human-facing leader and ordinary AT child—and state the smallest durable distinction, mandate evidence and actual enforcement each requires.
- Model a file-native repository lane as a resource state machine: claimant, scope, mutation boundary, landing/release boundary, stale-state behavior and read-only exceptions; compare it with worktrees alone, one-agent/one-task and a global scheduler.
- Map native provider observations and instruction-reader consequences to H1/H8/H9, separating availability, one successful observation, provider reliability and semantic preservation.

### Challenge

- Attack the no-dialogue design with clarification, failed evidence, revision, unavailable holder, frozen-amendment and record-recovery cases; reject any design that merely moves conversation into an unowned file or hides a material decision.
- Try to remove the named principal/LEAD and then try to justify it with shared-host continuity, cross-session delegation and provenance; reject identity-derived authority and prompt-only least privilege in both directions.
- Attack a single mutating lane with safe independent paths, stale reservations, abandoned work and human/agent siblings; reject both uncontrolled mutation and a maintained global scheduler unless the simpler file-native rule fails.
- Seek disconfirming provider and compression evidence: alternate checkpoint placement, capability/readback gaps, conflicting loaded instructions, exact-reader loss and rare continuation edges.
