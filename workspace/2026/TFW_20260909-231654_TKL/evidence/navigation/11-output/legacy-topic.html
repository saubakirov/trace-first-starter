    F37 A measurement without its method and its reference revision is a snapshot, not a measurement — and a count in shipped prose is a maintenance obligation. It recurred through five rounds of one task, in both halves — the count, and the revision the measurement was taken from. The discriminator that settles each case in one question: does the sentence still make its point without the number? One journal event exceeds the ceiling does, so the denominator goes; the check exits 1 does, so the task count goes. Where the number is the point it stays and gains the command that re-derives it. Two competent readers measuring the same corpus figure got different answers — 114/117/118 against 118/119/120 — because the answer depends on which paths are swept and whether the commit or the working tree is read, and one denominator moved between two commands a minute apart when a neighbouring session's uncommitted event landed. The same rule governs a byte-identity claim: identical means identical to a named revision, and measured from the wrong revision four of one round's forbidden paths read as violated, while from the right one none did. A figure's cost is every site the same commit touched — one false count stood at six script sites, at consolidated knowledge and in the CHANGELOG entry, and only the entry has anyone whose job is to check it — which is why subtraction is the only repair that scales to sites nobody will revisit. The general rule: state the fact, name the command, quote no count a neighbour can move ✅ verified RF TFW_20260902-112841_RDP §7 F13, F18, F19, F21, F22; REVIEW TFW_20260902-112841_RDP §7 FC1 (rev2), FC1 (rev4), F26 (rev5) 2026-09-03
    F38 A bound whose only reader runs after the act it governs cannot be complied with, and a bound with no reader at all is not a bound. A bound on an immutable artifact is enforced at the moment of writing or not declared at all; the resolution shape already exists in §5's two-act table for UNDECLARED — a tool never, an accountable person yes, the correcting event being what makes it a trace.
