### Smallest executable pilot proposal

1. **Select before running.** Owner/Coordinator chooses the actual TFW case and one software process, responsible human(s), environment, bounded time budget and acceptance basis in TS. Documentation generation is a prepared candidate, not the final software selection. Source inspection alone does not cover distributed systems, HTTP/database behavior or other stacks.
2. **Fix grounds independently.** A Reviewer checks the scenario facts and response criteria directly against authoritative sources, separately from the explanation. Record legitimate alternative reasoning and unknowns before observing a response. Reject shared explanation/key errors. Verify actual environment/output before any runtime claim.
3. **Establish fair baseline.** Select B0/current means before the trial, including existing useful diagrams and normal assistance. Compare adequate C1* under stated content/access/help conditions. Add C2* only for a named difficulty; make the same decision-relevant facts available in C1*. Record prior familiarity, order and exposure.
4. **Observe a person using the material.** Provide enough whole-system orientation for their responsibility, then a consequential variation not already answered for that person. Ordinary source access remains allowed. If they request the answer, provide it and classify actual assistance honestly; such an observation alone cannot fulfill unfamiliar-change reasoning. Preserve actual response or attributable observation, material correctness/omissions and justified uncertainty. Do not substitute an agent's response.
5. **Observe change and purpose.** Use a real or explicitly controlled material change and a nonmaterial edit; record affected source/claim, owner, repair/reuse and cost. Across pilots include apparent local progress that may undermine purpose, an authorized adaptation and unresolved outcome assumptions, using the existing Purpose Check.
6. **Judge and simplify.** Independent review checks source fidelity, scope and actual evidence. Keep added structure only for observed decision benefit within the agreed cost basis; omit it when adequate simpler means suffice. Unmeasured or confounded advantage is inconclusive. Owner accepts actual framework changes through the ordinary route.

One participant per responsibility is a possible bounded feasibility choice, not a population study. With one person, practice/order effects remain; a faster later answer is not a causal representation effect. A retained unfamiliar-scenario observation and an appropriate simpler baseline remain required even if C2* is omitted. No routine unaided retention claim is needed; if it is tested separately, report it separately.
