## Findings

### C1 — Manual ingestion is a fair comparator; recurring practice is the real question

The [original Karpathy revision](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f/ac46de1ad27f92b28ac95459c782c07f6b8c964a) explicitly permits human-directed, one-source-at-a-time ingestion and review. It does not require an autonomous global watcher. Its useful distinction is deliberate linked synthesis, reuse of useful answers and inspection for contradictions or neglected links. The earlier successful body inspection is reused; the Challenge refetch timed out and supplies no fresh confirmation. This immutable revision remains the cited pattern, not a community product or measured maintenance result.

Existing TFW knowledge/docs work can, on request, inspect selected sources, retain scoped dispositions and prepare an owning reference explanation. Extract's service specimen already gives A the same substantive account as C. Consequently, “TFW is requested, wiki is automatic” is rejected as an unfair contrast.

| Proposed gap | What the inspected evidence establishes | Smallest response |
|---|---|---|
| Absent configured practice | The inspected TFW routes do not establish a standing operation that maintains every useful topic/entity synthesis. This is scoped absence of a declared responsibility, not whole-repository impossibility. | Name a recurring question, existing carrier, review trigger and accountable producer only if recurrence is useful. |
| Missing convenient entry | Existing claim/source routes do not by themselves demonstrate that a reader can readily find the needed cross-source explanation. No human retrieval failure was observed. | Improve one existing entry or attach the same explanation; compare actual use before adding a store. |
| Missing technical capability | No necessary platform capability has been shown missing: Markdown, references and existing qualification work can express the demonstrated accounts. | Do not prescribe a new platform from this research. Test only a specific limitation if one emerges. |

The cost comparison must be symmetric. Selected ingestion, agent-written summaries, contradiction checks and current-use review require attention in either arrangement. A recurring topic can save reconstruction or create stale text. Neither near-zero wiki maintenance nor effortless TFW compliance is established.

### C2 — Models have different grounds, and a correct abstraction may survive change

Extract E4's phrase “scoped interpretation unless independently observed” is too broad. It is corrected here for synthesis:

| Assertion kind | Sufficient kind of ground for that assertion | What it does not prove |
|---|---|---|
| Approved intended design | A valid scoped design decision and its authority | Implementation or execution conforms |
| Structurally supported relation | Inspected code/configuration and stated extraction or reading rules at an exact revision | The relation was exercised, reachable in every environment or effective in practice |
| Proposed/inferred relation | Explicit reasoning and assumptions, marked as a proposal or inference | Approval, structural verification or observed behavior |
| Observed execution | Identified observation with environment, time and coverage | Universal behavior beyond that observation |

“Model” names a representation, not one epistemic class. A view may contain several classes if their distinction is legible. More precise provenance avoids both unjustified certainty and unjustified dismissal of approved design.

In the documentation specimen, the abstract dependency “selected sources feed the generator” remains valid after an individual source leaves selection. A source-specific inclusion claim and its explanation become affected. The maintainer checks dependency at the level actually asserted; there is no obligation to change an unaffected abstract edge. Conversely, a model explicitly asserting the moved page is selected must be corrected. One authority per claim means a clear governing disposition, not a requirement to propagate every source edit through every presentation.

In the service specimen, a signed notice does not establish amendment authority. A model can accurately portray the proposed North route before acceptance if it labels that status. A view that silently renders it as operative fails regardless of whether its syntax is valid or its prose agrees.

### C3 — Documentation attachment is real, but path and format assumptions matter

The [official docs import reference](https://docs.structurizr.com/dsl/docs) was successfully rechecked during Challenge on 2026-10-24. It requires a relative documentation path in the parent file's directory or a subdirectory. The default importer reads Markdown/AsciiDoc in the selected directory in alphabetical order and includes images from it and subdirectories. This does not establish arbitrary upward traversal or selective single-file inclusion.

Two candidate arrangements remain: place the parent model file at a suitable ancestor of the deliberately selected documentation directory, or prepare a bounded derived presentation directory. Neither has been installed or tested here. A broad existing directory may import more prose than intended, while a derived copy adds regeneration and stale-copy risk. Choose the smallest source scope and verify imported content and links in an authorized run; do not copy canonical material merely to claim integration.

The earlier [ADR reference](https://docs.structurizr.com/dsl/adrs) inspection establishes a format-aware importer, not direct compatibility with TFW's record grammar. Direct TFW ADR import remains unknown. Ordinary documentation attachment is a candidate alternative, also subject to an actual fidelity check. This uncertainty affects implementation choice and cost, not the conceptual possibility of displaying prose with views.

### C5 — A discriminating next comparison must permit “no addition”

Fix the answer grounds, content, help, exposure and time cap before comparing. If finding synthesized meaning is the demonstrated difficulty, try one maintained topic in an existing carrier. Measure preparation and affected update/review work as well as use. Record errors, omissions, assistance and subjective clarity separately. A graph or topic can clarify the relation to a goal, but cannot prove that an activity advances that goal; the policy-authority and site-reachability gaps remain substantive in both specimens.
