## External Planning Anchors

- Official Git diff documentation reports binary `--numstat` records as `-`/`-`, not `0`/`0`, and defines NUL-delimited machine-readable path output. This makes LOC = N/A and logical artifact identity falsifiable at replay rather than a prose convention: <https://git-scm.com/docs/diff-options>.

This is counterevidence to treating either LOC or one-file-equals-one-unit as a complete cross-domain size measure: <https://www.loc.gov/preservation/digital/formats/sustain/sustain.shtml>.

It supplies an external model for testing the Coordinator boundary without assuming every discovered implementation fact is authorized scope: <https://www.nasa.gov/wp-content/uploads/2018/09/nasa_systems_engineering_handbook_0.pdf>.
