## Design Analysis — row 2 clause (b)

The design intends one neutral gate with an explicitly evidence-limited initial adapter and a strict
native all-eight admission rule for later providers. That is coherent: the initial profile is an
honestly disclosed bootstrap candidate, while expansion cannot promote documentation, proxy evidence,
or partial receipts into another execution promise. The implementation collapses those cases by
quantifying over every profile. This breaks the design's only current positive profile without making
the later-provider rule safer, and the separated test projections conceal the break.

Research iteration 3 corroborates the approved distinction without changing its authority: D3/H10
mark Codex G1–G7 field-supported and G8 uncontrolled; A1 says Codex work may proceed at its current
evidence level while a Claude profile waits for the complete gate; Q4 leaves controlled Codex G8 for
a later run and says it is non-blocking for present planning.
