## 2. Key Decisions

1. **Staging layout kept** (RES iteration 1 D4): clone inside `.tfw/.upstream/.clone`, copy, check,
   delete, so every pinned text that reads `.tfw/.upstream/.tfw/…` still works and no gitlink window
   stays open during the apply.
2. **Untagged route without `remote add` or promisor configuration.** TS §6 listed both; on Git 2.42
   and 2.43 a filtered fetch by URL registers the promisor itself and the lazy checkout works
   (GitHub and local, 622.81 KiB, 95/95). Four commands instead of six.
3. **Fallback writes only `.tfw`.** "Without filter and sparse options" is kept, with `--no-checkout`
   and `checkout <SHA> -- .tfw`, because the tag's tree holds 225-character paths that a whole-tree
   checkout would write into staging.
4. **Tag recheck is exact.** The clone is deleted before adapter sync, so the tag's own
   `git ls-remote <upstream> refs/tags/<tag>` line is recorded at the pin and must be unchanged
   before sync; this works for annotated and lightweight tags alike.
5. **Staging must start empty.** A leftover `.tfw/.upstream/` is removed with disclosure first; a
   copy onto an existing `.tfw/.upstream/.tfw` would nest and pass stale files to Step 3.
6. **The fallback discloses through the size rule,** which still runs on the repeated commands, so
   the text states disclosure once.
7. **Install prompts defer the copy to `quickstart.md`.** "Copy .tfw/" would carry the upstream's
   config, knowledge state and receipts into the receiver (F23); `quickstart.md` Step 1 keeps the
   exclusions.
8. **The one-time update hint bootstraps from the fetched text:** clone and sparse-set the target,
   then continue with its own Step 0 from the size check, so the hint stays short and exact.
9. **Archive list = research R3 plus AC-5's three state exclusions** (130 files at the Candidate).
10. **Kazakh uses «релиз»,** the README's existing word; Russian keeps «фреймворк», «выпуск».
11. **The version line is a paragraph after the card's field list,** named as the card's first row,
    so the eight fields keep their numbering.
