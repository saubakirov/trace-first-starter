## Source and decision context

Money, token volume and time answer different questions. The common format keeps source identity,
schema version and contribution revision distinct, preserves unknowns and identifies actual
declared owners/roles. A dated Standard API equivalent is not a subscription invoice. Task calendar
elapsed, native completed-turn duration and model-generation duration remain different quantities.
Product keywords filter overlapping interests; one primary area supplies additive grouping.

The JSONL is compact source/day/model data, not a mandatory per-call archive. Returned corrections
replace prior verified bounds once; phase leaves and root coordination are counted once. The
report describes achieved value through existing RF/REVIEW evidence without a subjective quality
score. Hooks, a shared database/BI service, human time tracking, tax/accounting treatment and
subscription allocation are outside this accepted MVP.
